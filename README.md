# keystone-field-service-management
A full-stack field service management platform built with Spring Boot, React, TypeScript, and PostgreSQL.
KEYSTONE – Field Service Management System

 Project Overview
KEYSTONE is a full-stack Field Service Management (FSM) platform designed to streamline maintenance operations for commercial facilities.

The system aims to help organizations manage work orders, dispatch technicians, track service requests, monitor SLA compliance, and manage field operations through a centralized platform.

 Technology Stack

Frontend
- React
- TypeScript

Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication

Database
- PostgreSQL

 Planned Features
- User Authentication and Authorization
- Role-Based Access Control
- Work Order Management
- Technician Dispatch and Management
- Service Request Tracking
- SLA Monitoring
- Parts and Time Tracking
- Interactive Admin Dashboard
- Customer Self-Service Portal
